# Godot read-only Agent preview: host design

This preview binds exactly one explicitly connected Godot session to an Agent session. The host registers the actual connected project and bridge instance in its Rust engine registry and retains the exact connection token and shared session handle. The frontend never supplies a project identity, generation, tool definition, command, or bridge token. Only the fixed project-info and scene-tree tools are registered. Changing the target means launching/connecting a separate session, not redirecting an existing run.

A user supplies a full Chat Completions URL, model, and optional bearer credential. Creating the fixed session is an explicit action and does not make a model request; sending a message starts it. No provider, credential, proxy, or previous application state is implicitly selected. Configuration, history, and credentials live in process memory. The frontend clears the password input after submission. Closing or retiring a session cancels its active run and drops resources after actual in-flight tool work drains. Memory copies are not guaranteed to be securely erased. Models receive user messages and the editor data returned by allowed tools.

The host tracks Agent sessions and runs by opaque IDs and owning webview. Start reserves a run before spawning it. Poll responses contain both identities and ordered text fragments; the UI ignores replies for old sessions/runs and after cancellation. Cancellation acknowledges a request, not completion: an already dispatched blocking read may still be draining. While a run is active, a worker checks the tracked child/session state without reconnecting. A terminal state, release, or close retires the exact registry token and cancels the run before waiting on the shared session lock; old work cannot be retargeted. Registry and host maps are never locked across network IO or await. Credentials, upstream response bodies, endpoints and raw bridge identities are never put into errors or logs. The underlying v1 Godot bridge has the documented local trust limitations; this preview is not a complete Agent migration.

Cargo compiles the Agent dependencies only with the Godot feature; Unity and Unreal standalone feature builds remain independent.

A cancelled run remains unavailable for reuse until any admitted tool read drains. A late cancellation of a completed run preserves its result. A retired run reports the unavailable target and keeps its poll receipt until collected or closed. Once the run drains, the host drops the session and provider even if the receipt is never collected. The active-run worker checks the child process and the last observed session state. A bridge-only disconnect while the editor stays alive is detected on the next bridge read.
